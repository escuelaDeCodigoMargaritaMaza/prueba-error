# Test Statistics Playground

Hola. Necesito hacer una página web interactiva en la que explique qué es la sensibilidad, la especificidad, el VPP, el VPN, los LR, las curvas ROC, Bayes y los nomogramas.

Por interactivo me refiero a que puedas escoger el número de pacientes, verdaderos positivos, etc. Quizá hasta tener algún personaje que lo explique.
